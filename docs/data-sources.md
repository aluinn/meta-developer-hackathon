# Data sources

Room world does not ship or download any dataset. This page lists every kind of data it touches.

| Data | Where it comes from | Where it is used |
|---|---|---|
| Room scans (`.glb` / `.obj`) | Supplied by the user. The project was built around phone LiDAR scans exported from an external scanning app; scanning itself is not in this repo | Uploaded to `POST /scan`; stored on the server under `server/scans/` (git-ignored) |
| Example rooms | The authors' own scans of a studio apartment and Zac's room (`web/public/examples/*/scan.glb` and `world.json`), plus a made-up example room and a narrow-gap room made from boxes | The four ready-made rooms; the only `.glb` files committed |
| Furniture labels and roles | Generated by Meta's SAM 3.1 and Muse Spark from the scan | `world.json` (see [system-overview.md](system-overview.md)) |
| The character picture | Generated with Meta's Muse Image from [character-prompt.md](character-prompt.md) | `web/public/assets/character.png`; listed in [THIRD_PARTY.md](../THIRD_PARTY.md) |
| Before and after pictures, layout proposals, transcripts | Generated by Meta models on request | Shown in Work mode; layout results kept per scan |

Scan files are never committed (see `.gitignore`). Do not upload scans of places you would not want shared; see [SECURITY.md](../SECURITY.md). Check Meta's terms for generated images before reusing them.
