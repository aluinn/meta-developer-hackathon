## Context
The README hero is a still screenshot, and a comment in the README marks where a short recording should go.

## Task
Record 10 to 20 seconds of the live site or a local run: pick a ready-made room, show it labelled in Work mode, then run the clearance check, or show a few seconds of Game mode. Keep it small (under about 5 MB, so it loads quickly) and use only the ready-made rooms so no private scan is shown.

## Acceptance
- The file is added under `docs/assets/` with a new name (do not overwrite existing images).
- The README hero uses it, with the existing screenshot kept as the fallback in a comment or below the fold.
- Alt text describes what the recording shows.

## Pointers
- `README.md`: the `HERO PLACEHOLDER` comment
- `docs/assets/`: existing screenshots (`rw-*.png`)
